# Slate

Formerly Life Planner. A personal day planner that installs as an app on Android and on a laptop. No app store.

**Open:** https://hemsaivp.github.io/life-planner/

- Android: open the link in Chrome › menu ⋮ › Install app.
- Laptop: open the link in Chrome or Edge › install icon in the address bar.

Everything you tick is stored on your own device. If you turn on sync (Setup › Sync your phone and laptop), a copy is also kept in your own private GitHub repository so your devices match. Nothing is sent anywhere else. Works offline after the first open and updates itself when this repository changes.
